コダックの定理

基本式

[ \sum_{i=0}^{n-1}2^i = 2^n - 1 ] [ |{0,1}^n| = 2^n ] [ \Delta_{\max}=2^n-1 ]

nビットの二進数では、それぞれの桁が0または1のどちらかを取る。 したがって可能な組み合わせ数は指数関数的に増加する。

直感

1ビットなら0か1の2通り。 2ビットなら00,01,10,11の4通り。 3ビットなら8通り。 つまりビットが1つ増えるごとに可能な状態は2倍になる。

[ 2 \times 2 \times 2 \times \cdots = 2^n ]

定義

nビットの二進数とは、 n個のビット [ b_0,b_1,b_2,\dots,b_{n-1} ] から構成される数である。

このとき値は [ \sum_{i=0}^{n-1} b_i 2^i ] で表される。

定理

nビットの二進数で表せる整数の個数は [ 2^n ] である。

また最大値は [ 2^n-1 ] となる。

証明

各ビットは [ b_i \in {0,1} ] を取る。

したがって組み合わせ数は [ 2 \times 2 \times \cdots \times 2 ] であり [ 2^n ] となる。

さらに最大値は

[ \sum_{i=0}^{n-1}2^i ]

であり、等比数列の和から

[ \sum_{i=0}^{n-1}2^i = 2^n-1 ]

が成立する。

例

3ビットの場合

[ 000,001,010,011,100,101,110,111 ]

合計 [ 2^3 = 8 ] 通り存在する。

最大値は [ 111_2 = 7 ] である。

演習

問1： 8ビットで表せる整数の最大値を求めよ。

解答
[ 2^8-1 ] [ 256-1=255 ]
